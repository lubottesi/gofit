# GoFit

An early prototype of the GoFit landing page: hero section and a set of feature cards (nutrition, gym, calculators). Only the home page exists here - the nav links to other pages (academia, nutricao, calculadoras, conteudos) that aren't built yet.

See [gofit-oficial](https://github.com/lubottesi/gofit-oficial) and [gofit-oficial-oficial](https://github.com/lubottesi/gofit-oficial-oficial) for later, more complete versions.

## Stack

- HTML5
- CSS3
- Vanilla JavaScript (smooth scroll to the "descubra tudo" section)

## Running locally

No build step - open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
```

Then go to http://localhost:8000.
